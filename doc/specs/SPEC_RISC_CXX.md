RISC C++ Dialect
================

===================================

# 0: General Information:

===================================

- ABI: PEF based.
- Typing System: Weak.
- Output: NeAnt Assembler/Netwide Assembler.
- Platforms: OS X, POSIX, NeAnt.

===================================

# 1: Concepts:

===================================

- Dumbed down, C++ syntax and parsing, reduced to the strict minimum.
- Much more forgiving parsing in terms of ';' tokens.
- Great power is given to the preprocessor to manipulate the RISC-C++ code.
